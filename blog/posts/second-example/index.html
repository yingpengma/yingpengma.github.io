Aside: what goes in a folded note

A folded aside holds what some readers will want and others will skip: a derivation, a caveat, a longer example. It stays closed until clicked, so the essay reads straight through without it.

Code is set off by a thin rule on its left, like a quotation, a little smaller than the text, and scrolls sideways when a line is too long:

def recall(keys, values, query):
    scores = keys @ query
    return values.T @ scores

Inline code, like keys @ query, is set in a thin box within the line.
